## 复用与模块边界

- `work_catalog_yaml.persistence`：目录写锁、唯一历史命名、原子文件替换、带并发变更检查的批量提交/回滚。collection-detail、collection-info、索引缓存及组注册表共用；不依赖功能模块。
- `work_catalog_yaml.layout`：工作区路径解析及后端发现。源码启动、桌面运行、打包使用一致的后端列表；打包按功能目录收集前端资源。
- `work_catalog_yaml.paths`：两个 CLI 导出入口共用边界校验，拒绝绝对路径、父级跳转、Windows 驱动器相对路径和流语法。
- `media_directory_organizer.filesystem`：整理预览、执行和落地流程共用联接检测与普通文件扫描。
- 框架测试纳入 `scripts/test.ps1`，与功能测试及 JavaScript 行为测试统一运行。
