# 分辨率压制目录：保留已有正片布局

`1080p`、`720p` 等分辨率格式，只有正片和随集字幕时，不要求增加 `_Disc` 中间层。已经规范整理好的以下两种布局都应保留：

```text
作品根目录/
  作品_1080p/
    第01集.mkv
    第01集.ass
```

```text
作品根目录/
  作品_1080p/
    作品_1080p_01/
      第01集.mkv
      第01集.ass
    作品_1080p_02/
      第02集.mkv
      第02集.ass
```

已有规范分集目录可以保留，即使每集只有一个视频。不能仅因为“不满足多个视频版本”就把该目录重新拆平。

保留判断仍校验普通目录 / 文件、规范分集目录名、文件集号与目录一致，以及文件类型和所属分类。任意包装层、错集内容、图片 / 音乐 / 特典或链接目录不能因此被直接标记为全部整理完成。新来源的整理和真正多版本视频归档规则不变。
