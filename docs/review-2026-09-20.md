# 2026-09-20 工程审查、修复与优化

范围：框架 API/任务队列、三个功能模块、文件移动与恢复、资源缓存、前端生命周期、桌面打包校验、测试和架构文档。采用模块独立检查、交叉复查、临时数据故障注入及隔离浏览器验证。

本轮没有修改真实数据库或用户配置，没有移动真实媒体、创建快捷方式、提交/推送代码或重新打包。旧 EXE 不包含本轮修改。

## 已修复的问题

| 优先级 | 问题及影响 | 修复 |
| --- | --- | --- |
| P1 | `shutil.move` 在重命名失败后自动复制，可能覆盖并发出现的目标；复制后删除源失败还会留下未计入恢复的目标 | 前向移动与回滚共用禁止覆盖的移动函数；Windows 直接重命名，拒绝跨卷复制回退 |
| P1 | 移动或回滚被中断时，某些边界缺少恢复信息，可能错误宣称全部回滚 | 补齐系统操作完成但 Python 尚未登记、硬链接创建后中断、回滚过程中再次中断等路径；不确定状态返回 partial 和恢复明细，保留相关数据库更改 |
| P1 | 资源扫描使用 GET，却会写磁盘缓存，绕过仅针对写请求的来源校验 | 改为 POST JSON，前后端同步更新；跨站请求被拒绝，GET/HEAD 不执行扫描 |
| P1 | 编辑/删除记录及整理器引用将浮点数、布尔值强制转整数，可能操作错误记录 | 共用严格索引校验器，拒绝浮点、布尔、负数和越界值，保留十进制字符串兼容 |
| P1 | 收集情况根据当前扫描目录过滤已有年份，磁盘离线或目录不完整时可能丢失记录 | 已记录年份独立保留；保存不再扫描或过滤目录年份，界面提供明确的离线选项 |
| P2 | 切换收集页、刷新枚举、慢请求返回会覆盖未保存编辑或更新错误页面 | 保留草稿；引入生命周期和加载代次校验；限制重复加载/保存；加载失败保留原表单 |
| P2 | 离线年份取消勾选后选项消失，无法撤销；长说明挤成多行窄列 | 选项快照保持至显式重读，允许重新勾选；离线提示占两列，禁止复选框收缩 |
| P2 | 只有文件、没有下级目录的资源节点可能无法展开 | 共用树节点投影，文件也计入可展开判断；保留懒加载计数，兼容旧缓存的只读修正 |
| P2 | 追加已有作品预览重复读取同一个 YAML，记录与哈希可能来自不同瞬间 | 解析与哈希使用同一份字节快照，减少重复读取 |
| P2 | 磁盘任务排队无上限，拥塞时继续接收请求 | 每个队列最多接收 64 个未完成操作（包含执行中），满载明确返回 503 和重试提示 |
| P2 | 缺少可复用的源码与桌面包一致性检查，容易发布旧资源或不匹配 ZIP | 新增只读校验脚本，打包结束自动检查 Python、前端、默认配置、共享目录及 ZIP 一致性 |

空目录清理也在执行时重新检查根目录边界，禁止把作品根目录自身当作待删除来源。以上文件系统行为只通过临时目录测试，没有操作收藏盘。

## 复用、清理与性能

- `input_validation.parse_record_index` 替代不同模块中宽松且重复的索引转换。
- `resource_tree` 的共用投影替代摘要/缓存树的重复字段构造，统一懒加载语义。
- `execution` 的无覆盖移动逻辑同时服务于执行和回滚，移除不安全的复制回退。
- 已有作品追加预览从重复读取改为一次快照；保存收集情况从扫描一次完成目录改为零次扫描。
- 多文件进入同一目标目录时，每个目标父目录只调用一次创建操作。
- 抽出可独立执行的桌面产物校验，后续无需临时编写 EXE/ZIP 检查脚本。
- 保留仍在使用的兼容模块与真实数据；没有为了缩减文件数量删除导入兼容层或历史资料。

## 接口兼容和后续边界

- 自定义扫描调用需从 GET 改为 `POST /api/collection-detail/resource-libraries/scan`，JSON `{}` 可用。内置前端已同步更新。
- 满载响应为 HTTP 503、`code: api-queue-full`、`Retry-After: 1`。不会自动重试保存、移动等写操作。
- 记录索引仍支持非负整数及十进制字符串，但不再接受 `true`、`1.0` 等宽松输入。
- 现有整理设计在同一作品根目录内移动；跨卷移动现在明确失败，不隐式执行复制/删除。
- 仍无跨进程/断电恢复的持久化事务日志。本轮完善可捕获异常与中断的恢复报告，不保证强杀后的自动恢复。
- 整理前端和落地协调模块仍偏大。后续宜按作品绑定、预览树、事务执行、快捷方式重试分阶段拆分，保留现有测试约束；不建议一次性重写分类与落地逻辑。
- 冷启动配置加载仍明显慢于热请求；资源缓存展开仍有重复配置读取，可在明确配置失效规则后继续优化，不应以长期缓存掩盖配置变化。
- 本轮源码优化已完成，未提交、未推送、未重新打包；使用桌面 EXE 前需另行构建更新。
